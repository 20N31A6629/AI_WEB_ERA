________________________________________
1) Getting Started (User Steps)
1.	Open the app
o	Save the file as index.html.
o	Double click to open it in any modern browser (Chrome, Edge, Firefox, Safari).
2.	Add an image (3 ways)
o	Click → Choose File: Select a local image (JPG/PNG/GIF/WebP).
o	Drag & Drop: Drop an image onto the dotted dropzone.
o	Use Webcam: Click 📷 Use Webcam, grant permission, then click 📸 Capture.
3.	Generate a motivational quote
o	Click ✨ New Quote (or press G).
o	The quote appears over the image on the canvas.
4.	Edit text appearance
o	Change Font Family, Text Size, Color, Alignment, Line Height.
o	Toggle Text Shadow for readability.
o	Toggle Background Overlay and adjust Overlay Color + Opacity.
5.	Position the text
o	Drag the text directly on the canvas.
o	Nudge with arrow keys (hold Shift for bigger steps).
o	Double click the canvas to center the text.
6.	Adjust the image
o	Use Brightness and Contrast sliders.
o	Rotate (0–359°) or quick buttons for 90/180/270°.
o	Crop Mode → drag handles → Apply (works when rotation is 0°).
7.	Randomize look
o	Click ⚡ Random Style (or press R) to get a fresh layout/color/typography combo.
8.	Themes & Background
o	Toggle 🌓 Theme (or press D) for light/dark.
o	Click 🎨 Gradient to randomize the page background gradient.
9.	Download the result
o	Click ⬇️ Download (or press Ctrl/Cmd + S) to save the final PNG with the quote baked in.
10.	Reset
o	🧹 Reset Settings: Resets styles/controls but keeps your current image.
o	🗑️ Reset All: Clears LocalStorage and reloads the app.
